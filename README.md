## Running Solutions

### Python

To run a Python solution:

```bash
python3 python/problemName.py
```

For example:

```bash
python3 python/twoSum.py
```

### C++

Compile the program:

```bash
g++ cpp/problemName.cpp -o solution
```

Then run it:

```bash
./solution
```
